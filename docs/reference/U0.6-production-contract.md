## Frontera pública

| Aspecto | Valor |
| --- | --- |
| URL canónica | `https://webblueprint.eliasworks.uy` |
| Base del navegador | `/` |
| Servidor FTP | `ftp.eliasworks.uy:21` |
| Usuario FTP | `luis@eliasworks.uy` |
| Destino FTP | `public_html/webblueprint/` |
| Fallback SPA | `dist/.htaccess` |
| Fuente de despliegue | artefacto `web-production` de un CI exitoso de `main` |
| Secret requerido del repositorio | `FTP_PASSWORD` |

## Regla de aislamiento

WebBlueprint es propietario únicamente de su directorio dedicado de despliegue. El despliegue no debe escribir en la raíz `public_html/` ni modificar el portafolio Laravel publicado en `https://eliasworks.uy`.

## Rutas de aceptación

El smoke de producción valida:

- `/`
- `/apps`
- `/docs`
- `/components`
- `/demo/pet-shop/dashboard`

Estas URLs deben resolver directamente desde el subdominio, incluyendo recarga del navegador y comportamiento de deep links mediante el fallback de Apache.
