# U0.6 · Production Contract

## Public boundary

| Concern | Value |
| --- | --- |
| Canonical URL | `https://webblueprint.eliasworks.uy` |
| Browser base | `/` |
| FTP server | `ftp.eliasworks.uy:21` |
| FTP user | `luis@eliasworks.uy` |
| FTP target | `public_html/webblueprint/` |
| SPA fallback | `dist/.htaccess` |
| Deploy source | successful `main` CI artifact `web-production` |
| Required repository secret | `FTP_PASSWORD` |

## Isolation rule

WebBlueprint owns only its dedicated deployment directory. The deployment must not write to `public_html/` root and must not modify the Laravel portfolio deployed at `https://eliasworks.uy`.

## Acceptance paths

The production smoke validates:

- `/`
- `/apps`
- `/docs`
- `/components`
- `/demo/pet-shop/dashboard`

These URLs must resolve from the subdomain directly, including browser refresh/deep-link behavior through Apache fallback.
