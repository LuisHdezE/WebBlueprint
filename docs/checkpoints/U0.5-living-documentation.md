# U0.5 · Documentación viva / Galería de componentes

Estado: **LISTO PARA REVISIÓN**  
Base: `main@fd51533a7148f136c84b26e270cef3db2acc375d`

## Objetivo

Sustituir los placeholders existentes de documentación por documentación pública útil construida alrededor de componentes y contratos que ya existen.

## Entregado

- `/docs` es ahora un punto de entrada real a la documentación viva;
- `/components` es ahora una galería real de componentes;
- los componentes compartidos actuales se documentan con ruta fuente, props, variantes, estados y ejemplos de uso;
- `ApplicationCard` y `ApplicationPreview` renderizan ejemplos vivos desde datos de `applicationRegistry`;
- las variantes gobernadas de menú izquierdo se previsualizan desde `leftMenuVariants`;
- la documentación de shells consume la fuente gobernada de variantes en lugar de duplicarla;
- la metadata de documentación está centralizada y cubierta por tests de invariantes;
- el smoke existente del Motor de exportación permanece verde en CI.

## Límite

U0.5 documenta lo que existe hoy. Los componentes futuros se documentan cuando entran en el producto, no mediante especificación especulativa anticipada.
