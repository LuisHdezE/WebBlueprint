# U0.5 · Living Documentation / Component Gallery

Status: **ACTIVE**  
Base: `main@fd51533a7148f136c84b26e270cef3db2acc375d`

## Goal

Replace the existing documentation placeholders with useful public documentation generated around components and contracts that already exist.

## Scope

- turn `/docs` into a real living-documentation entry point;
- turn `/components` into a real component gallery;
- document current shared components with source path, props, variants, states and usage examples;
- render real `ApplicationCard` and `ApplicationPreview` examples from the application registry;
- keep documentation metadata centralized and test its invariants.

U0.5 does not invent future components. The catalog grows when reusable code actually enters the product.
