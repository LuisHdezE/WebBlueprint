Este checkpoint sustituye, para decidir si U0.2 puede salir de Draft, la instantánea de estado pendiente registrada en `U0.2-public-showcase-composer-shell.md`. El checkpoint anterior se conserva como evidencia histórica.

## Resumen de cierre

U0.2 satisface el gate de fundación del producto para la presentación pública y la frontera autenticada del Compositor.

Entregado y reconciliado:

- landing pública, catálogo de aplicaciones y superficies de detalle de aplicación;
- routing compartible para demos de aplicaciones;
- frontera autenticada `/composer/*` con abstracción de sesión reemplazable;
- `LeftAppShell` reutilizable consumido por el Compositor y las demos públicas;
- únicamente variantes gobernadas de menú izquierdo;
- registro de aplicaciones como fuente compartida de metadata pública/demo;
- densidad Visual V2 de Style 1 y refinamiento del color de marca;
- navegación pública responsive y comportamiento del drawer de aplicaciones;
- el menú público móvil ahora se cierra después de navegar a otra ruta;
- gobernanza de publicación canónica bajo `eliasworks.uy`;
- arquitectura de hosting de EliasWorks auditada sin tratar Render como destino de producción;
- portabilidad ruta/subdominio mediante `BASE_URL` de Vite y basename de React Router;
- fallback SPA de Apache proporcionado por `public/.htaccess`.

## Cierre visual/responsive

Visual V2 incorporó el feedback explícito de densidad/color registrado durante U0.2:

- reducción de espacios vacíos y paddings sobredimensionados;
- escala de títulos contenida;
- proporciones compactas de sidebar/topbar;
- lenguaje fresco de azul primario/acciones en lugar de dominio casi negro;
- superficies Style 1 con prioridad clara;
- grids y navegación mobile-first.

Una auditoría responsive final de código cubrió:

- landing;
- catálogo de aplicaciones;
- detalle de aplicación;
- login;
- Compositor de aplicaciones;
- demo pública de Pet Shop;
- shells compartidos público y de aplicación con navegación izquierda.

La auditoría encontró un defecto accionable de comportamiento móvil: el menú público persistente basado en `<details>` podía permanecer abierto después de navegar a otra ruta. Ese comportamiento se corrigió antes del cierre.

Ningún commit posterior cambió el estilo Visual V2 aprobado después de esa corrección.

## Evidencia de EliasWorks/deep links

El dominio canónico de publicación se mantenía como:

```text
https://eliasworks.uy
```

Render permanecía únicamente como evidencia de preview no canónica.

La raíz de EliasWorks ya estaba ocupada por la aplicación de portafolio, por lo que WebBlueprint no debía sobrescribir `public_html/` indiscriminadamente. La ruta/subdominio gobernada exacta y el cableado de CD permanecían como asuntos de U0.6.

U0.2 únicamente establecía preparación para despliegue:

- `BrowserRouter` consume `BASE_URL` de Vite;
- los despliegues bajo ruta pueden usar una base adecuada de Vite;
- los despliegues en raíz/subdominio pueden conservar `/`;
- `.htaccess` proporciona fallback SPA para rutas directas y recargas.

CI verifica que el build de producción contenga realmente `dist/.htaccess`.
