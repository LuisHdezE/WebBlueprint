PR: **#4**

## Objetivo

Convertir el Compositor autenticado desde un shell descriptivo en un flujo utilizable de configuración de aplicaciones.

## Flujo entregado

`Aplicación → Marca → Preset → Funciones → Páginas → Navegación → Revisión`

El Compositor ahora posee una única configuración persistente de proyecto y deriva el manifest desde ese mismo estado.

Implementado:

- nombre, slug y descripción editables de la aplicación;
- URL de logo y color de acento para la marca;
- Pet Shop como primer preset respaldado por el registro;
- los presets inicializan funciones, páginas y shell sin sobrescribir la identidad ni la marca del proyecto;
- modo de proyecto vacío;
- selección manual de funciones desde el catálogo del Compositor derivado del registro;
- selección manual de páginas desde el catálogo de páginas derivado del registro;
- selección gobernada de variante de menú izquierdo;
- vista previa de navegación en vivo;
- borrador persistente en el navegador mediante almacenamiento local;
- vista previa determinista de un manifest con forma de `webblueprint.json`;
- validación de identidad de la aplicación y color de acento;
- descarga directa de `webblueprint.json` cuando la configuración es válida;
- cobertura unitaria para IDs estables, comportamiento de presets, validación y generación del manifest.

## Revisión responsive

El Compositor mantiene el enfoque mobile-first:

- la navegación por pasos pasa de siete columnas a disposiciones compactas de varias filas;
- formularios, vista previa de marca y grids de selección se apilan antes de los breakpoints amplios;
- navegación y revisión del manifest usan disposiciones responsive apiladas antes de dividirse en escritorio;
- la barra lateral de estado del proyecto pasa al flujo normal del documento debajo del wizard hasta `xl`;
- el contenido ancho del manifest hace scroll interno en lugar de ensanchar la página;
- los `WorkspaceShell` / `LeftAppShell` compartidos continúan proporcionando el drawer de navegación móvil.

No se introdujo un shell separado para el Compositor.
