# U0.3 · App Composer Core

Status: **ACTIVE**  
Base: `main@9f6f87cbd34630f95b2c76c67e03600505e0f0dd`

## Goal

Turn the authenticated Composer from a descriptive shell into a usable application-configuration workflow.

## Scope

U0.3 implements the flow:

`Application → Branding → Preset → Features → Pages → Navigation → Review`

The Composer must own a persistent project configuration, reuse the application registry as its initial preset source, and generate a live `webblueprint.json`-shaped manifest preview.

## Closure criteria

- application identity can be edited;
- accent/logo branding can be configured;
- a registered application can seed the Composer as a preset;
- features and pages can be selected manually;
- navigation shell and selected pages can be previewed;
- draft state survives browser refresh through local storage;
- manifest preview is derived from the same configuration state;
- tests cover deterministic configuration/manifest logic;
- CI remains green.

This checkpoint intentionally defines only the current stage. Final implementation details are reconciled when U0.3 closes.
