## Objetivo

Demostrar que un manifest válido del Compositor puede convertirse en un proyecto React independiente en lugar de permanecer únicamente como datos de configuración.

## Entregado

`Manifest del Compositor → archivos de proyecto generados → ZIP determinista → unzip → npm ci → npm run build`

La exportación v0 ahora:

- crea un proyecto React/Vite determinista a partir del manifest del Compositor;
- traslada identidad de la aplicación, marca, funciones/páginas seleccionadas y navegación gobernada a la aplicación generada;
- incluye `webblueprint.json`, `package.json`, `package-lock.json`, archivos fuente, configuración de Vite y README;
- deriva la metadata de dependencias npm desde el toolchain gobernado de WebBlueprint;
- crea un ZIP descargable desde el navegador sin añadir una dependencia de runtime para ZIP;
- expone la descarga ZIP únicamente dentro de la superficie autenticada del Compositor;
- mantiene las rutas públicas libres de controles de exportación;
- valida con tests unitarios la generación determinista del proyecto, la alineación del lockfile y la salida ZIP.

## Gate de runtime

CI #64 demuestra el recorrido real del archivo:

1. generar el ZIP;
2. extraer ese ZIP;
3. ejecutar `npm ci` dentro del proyecto extraído;
4. ejecutar `npm run build` dentro del proyecto extraído;
5. verificar que existan `dist/index.html` y `webblueprint.json`.

Resultado: **PASS**.

## Límite

U0.4 demuestra una exportación React determinista y compilable. La madurez más amplia de páginas y de la librería de componentes queda fuera de esta etapa y continúa de forma incremental en trabajos posteriores del roadmap.
