# U0.4 · Export Engine v0

Status: **ACTIVE**  
Base: `main@d1146ca6537997211e686dabf76b56850637114a`

## Goal

Prove that a valid Composer manifest can become a standalone React project rather than remaining only configuration data.

## Scope

`Composer manifest → generated project files → ZIP → npm ci → npm run build`

The v0 export is intentionally small and deterministic. It carries application identity, branding, selected features/pages and governed navigation into a generated React/Vite project.

## Closure criteria

- the export engine produces a deterministic standalone project file set;
- `webblueprint.json` is included in the generated project;
- the generated application reflects selected pages/features and branding;
- a browser-downloadable ZIP is produced without exposing export on public routes;
- the generated project includes reproducible npm metadata;
- CI proves the generated project passes `npm ci` and `npm run build`;
- unit tests cover project generation and ZIP determinism.

Final details are reconciled only after implementation exists.
