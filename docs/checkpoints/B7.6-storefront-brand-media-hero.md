## Goal

Move Storefront away from black as its primary brand color and introduce provider-driven commercial imagery.

The visual reference is the compact promotional carousel pattern seen on MANCRU:

- wide promotional image section,
- overlaid commercial copy,
- previous/next controls,
- slide indicators,
- CTA,
- floating WhatsApp action.

This implementation does not copy MANCRU assets. It reproduces the interaction pattern using reusable Storefront DTOs and demo media.

## DTOs

Added:

- `StorefrontThemeDto`
- `StorefrontMediaDto`
- `StorefrontHeroBannerDto`
- `StorefrontFloatingActionDto`

Extended:

- `StorefrontProductCardDto.image`
- `StorefrontHomeViewDto.heroBanners`
- `StorefrontShellViewDto.theme`
- `StorefrontShellViewDto.floatingAction`

## Theme

The demo brand now uses a configurable green palette:

- primary: `#16a34a`
- strong: `#15803d`
- soft: `#dcfce7`
- on-primary: `#ffffff`

These values live in Storefront data and are mapped to CSS variables by `StorefrontShell`.

Black remains available only as a neutral text/overlay color where appropriate. It is no longer the Storefront brand/action color.

## Media

Hero and product images are defined in `storefront.view.json`.

Presentation components consume:

- `image.src`
- `image.alt`
- `image.objectPosition`

No image URL is hardcoded in Storefront presentation components.

Current demo media uses externally hosted placeholder photography. Production templates can replace the provider data with local assets, CDN URLs or API-provided media without changing presentation components.

## Hero carousel

`/store` now includes a wide media carousel:

- three provider-driven banners,
- image + overlay,
- eyebrow/title/description,
- CTA,
- previous/next controls,
- slide selectors,
- responsive fixed visual height.

## Product imagery

Provider-driven images now render in:

- home featured product cards,
- product listing cards.

## Floating WhatsApp action

`StorefrontShell` renders a fixed floating action from `shell.floatingAction`.

The DTO supplies:

- label,
- aria label,
- href,
- icon type,
- background color,
- foreground color.

The current demo href stays internal (`/store/contact`) until a real WhatsApp number/integration is defined.
