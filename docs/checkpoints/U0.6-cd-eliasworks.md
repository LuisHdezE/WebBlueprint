## Goal

Publish accepted WebBlueprint `main` revisions automatically to its own independent subdomain under EliasWorks.

## Canonical production shape

- public URL: `https://webblueprint.eliasworks.uy`;
- browser application root: `/`;
- physical FTP target: `public_html/webblueprint/`;
- root `https://eliasworks.uy` remains the independent Laravel portfolio and is never overwritten;
- Render remains non-canonical.

## Delivery contract

`main push → CI quality/build → tested web-production artifact → FTP → canonical subdomain → production HTTP/deep-link smoke`

The deploy consumes the exact `dist/` artifact produced by the successful `main` CI run. It does not rebuild a second production bundle.

## Production acceptance

U0.6 is not fully closed until the first post-merge deployment proves:

- root URL responds successfully;
- `/apps`, `/docs`, `/components` and `/demo/pet-shop/dashboard` resolve through SPA fallback;
- the deployed bundle uses root `/assets/...` URLs, not path-hosted `/webblueprint/...` URLs.

Repository prerequisite: `FTP_PASSWORD` must be available to GitHub Actions for this repository.
