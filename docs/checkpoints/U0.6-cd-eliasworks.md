# U0.6 · CD → EliasWorks

Status: **CLOSED · PRODUCTION ACCEPTED**  
Production baseline: `main@854d3761c4625722e0ac91c1a45398aee37674bf`

## Goal

Publish accepted WebBlueprint `main` revisions automatically to its own independent subdomain under EliasWorks.

## Canonical production shape

- public URL: `https://webblueprint.eliasworks.uy`;
- browser application root: `/`;
- physical FTP target: `public_html/webblueprint/`;
- root `https://eliasworks.uy` remains the independent Laravel portfolio and is never overwritten;
- Render remains non-canonical.

## Delivered

- CI preserves the exact tested `dist/` output from successful `main` runs as artifact `web-production`;
- CD is triggered only by a successful `main` push CI workflow;
- the deployment job downloads that exact artifact instead of rebuilding;
- the production artifact guard requires `index.html`, `.htaccess`, root `/assets/...` references and rejects `/webblueprint/` path-hosted asset URLs;
- FTP writes only to `public_html/webblueprint/`;
- post-deploy smoke checks `/`, `/apps`, `/docs`, `/components` and `/demo/pet-shop/dashboard`;
- ADR-0005 fixes the independent-subdomain deployment decision.

## Production evidence

- PR #7 merged into `main` as `854d3761c4625722e0ac91c1a45398aee37674bf`;
- CI #74 passed on that exact merge commit;
- `web-production` artifact was created successfully from the accepted `main` build;
- deploy workflow `Deploy WebBlueprint to EliasWorks` run #1 consumed that exact artifact;
- first deploy attempt exposed the missing `FTP_PASSWORD` repository secret and stopped before publication;
- after secret configuration, FTP publication succeeded and created the first deployment state in `public_html/webblueprint/`;
- initial HTTP smoke exposed the missing DNS/subdomain mapping without changing application code;
- after creating `webblueprint.eliasworks.uy` with document root `public_html/webblueprint` and enabling AutoSSL, the deployment workflow was rerun;
- final deployment attempt completed with every step `SUCCESS`, including production artifact verification, FTP sync and canonical-subdomain deep-link smoke.

## Delivery contract

`main push → CI quality/build → tested web-production artifact → FTP → canonical subdomain → production HTTP/deep-link smoke`

U0.6 is closed. Future accepted `main` revisions now follow this production delivery path automatically.
