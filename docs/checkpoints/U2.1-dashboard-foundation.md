# U2.1 · Fundación de Dashboard

Estado: **ACTIVO**  
Base: `main@22c40bd4e1a729483aed3b4de57fa6edf787397d`

## Objetivo

Implementar la primera vista guiada por U1 usando un consumidor real que fuerce contratos reutilizables de alto retorno, sin construir una librería especulativa.

## Alcance

U2.1 entrega únicamente:

- contrato compartido de metadata de página antes de la primera vista `ADAPT`;
- `Dashboard` como primera vista diferenciada;
- primitivas mínimas requeridas por ese Dashboard;
- frontera `DashboardDataProvider` con mock determinista;
- integración en la demo Pet Shop existente;
- propagación de `pageKey`, ruta, icono y grupo hacia Compositor/manifest/exportación;
- documentación viva de los componentes nuevos;
- tests de invariantes y CI verde.

## Fuera de alcance

- implementar las otras 25 vistas `ADAPT`;
- crear todas las primitivas del mapa U1.2;
- introducir una librería de charts de terceros;
- backend/API real;
- rediseñar los tres shells gobernados.

## Criterio de cierre

- la metadata del Dashboard no se duplica entre registro, demo y Compositor;
- el manifest conserva identidad técnica de página e icono;
- la vista consume `DashboardDataProvider`, no fixtures directos;
- loading/empty/error siguen representables por contrato aunque este incremento muestre el estado success por defecto;
- los componentes reutilizables nuevos están documentados;
- tests y build permanecen verdes.
