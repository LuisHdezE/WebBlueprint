## Decisiones

### Metadata de página

La identidad compartida vive en un registro técnico independiente de los presets. Una aplicación selecciona una `pageKey` y añade únicamente contexto propio, como la descripción de su demo.

El incremento no incorpora todavía las 26 páginas U1 al registro ejecutable. Solo se registran las páginas que ya existen en Pet Shop y la identidad gobernada del primer consumidor real. Las demás entrarán cuando tengan un consumidor U2.

### Datos

`DashboardView` depende de `DashboardDataProvider`. El mock es determinista y vive fuera de `pages/`, por lo que la vista no importa fixtures de dominio directamente.

### Gráficos

El resumen semanal usa barras CSS simples. No se añadió una librería de gráficos antes de tener una necesidad que justifique esa dependencia.
