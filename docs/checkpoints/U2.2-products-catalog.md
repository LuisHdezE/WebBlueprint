# U2.2 · Catálogo administrativo de productos

Estado: **ACTIVO**  
Base: `main@a0ac4d604c3aa0b13dfaed01d4f3c03b9cf93476`

## Objetivo

Implementar `product-catalog-admin` como segunda vista real de U2, extrayendo únicamente las primitivas reutilizables que este consumidor necesita.

## Alcance

U2.2 entrega únicamente:

- `ProductCatalogView` conectado a `/demo/pet-shop/products`;
- frontera `ProductsRepository` con mock determinista;
- modelos UI `ProductSummary`, `ProductFilter` y `ProductStockState`;
- búsqueda por texto y filtro por estado de inventario;
- `SearchField` reutilizable;
- `DataTable` reutilizable con API mínima;
- reutilización de `StatusBadge` para estado de stock;
- estados carga, vacío y error representables por contrato;
- documentación viva y ejemplos de los componentes nuevos;
- tests de filtrado/determinismo y CI verde.

## Fuera de alcance

- editor/alta de productos;
- detalle de producto;
- tienda pública;
- paginación remota;
- selección masiva y acciones por lote;
- ordenamiento avanzado;
- backend/API real;
- nuevas dependencias de tabla o formularios.

## Criterio de cierre

- `/demo/pet-shop/products` deja de usar el workspace genérico;
- la vista depende de `ProductsRepository`, no de fixtures importados;
- búsqueda y filtro producen resultados deterministas;
- `DataTable` y `SearchField` nacen con API mínima y se documentan;
- la tabla permanece usable en móvil mediante desplazamiento horizontal controlado;
- no se implementan variantes no requeridas por este consumidor;
- typecheck, lint, tests, build, smoke de exportación y fallback SPA permanecen verdes.
