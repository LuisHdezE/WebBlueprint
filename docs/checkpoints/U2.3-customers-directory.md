# U2.3 · Directorio de clientes

Estado: **ACTIVO**  
Base: `main@fe4d5e9e3627b141ef14daa5cdcca75198ef7dab`

## Objetivo

Convertir `customers` en la tercera vista real de U2 y validar que las primitivas extraídas en U2.2 se reutilizan fuera del catálogo de productos.

## Alcance

U2.3 entrega únicamente:

- `CustomerDirectoryView` conectado a `/demo/pet-shop/customers`;
- frontera `CustomersRepository` con mock determinista;
- modelos UI de cliente y filtros de relación;
- búsqueda por nombre, correo o teléfono;
- filtro por estado de relación;
- reutilización de `DataTable`, `SearchField`, `StatusBadge` e `InlineFeedback`;
- extracción de `SelectField` ahora que existe un segundo consumidor real de selección;
- refactor de Productos para consumir `SelectField` sin cambiar su comportamiento;
- extracción de `Avatar` como identidad mínima requerida por el directorio;
- documentación viva y ejemplos de los componentes nuevos;
- tests de búsqueda, filtrado, vacío y determinismo;
- CI verde sobre el HEAD exacto.

## Fuera de alcance

- ficha o edición de cliente;
- alta de clientes;
- historial completo de pedidos;
- segmentación avanzada;
- acciones masivas;
- paginación remota;
- backend/API real;
- nuevas dependencias externas.

## Criterio de cierre

- `/demo/pet-shop/customers` deja de usar el workspace genérico;
- la vista depende de `CustomersRepository`, no de fixtures importados;
- `DataTable` y `SearchField` demuestran un segundo consumidor real;
- `SelectField` sustituye los selects nativos equivalentes de Productos y Clientes;
- `Avatar` nace con API mínima y se documenta;
- búsqueda y filtro producen resultados deterministas;
- typecheck, lint, tests, build, smoke de exportación y fallback SPA permanecen verdes.
