## Goal

Increase commercial density in product grids.

The previous product cards were too wide and used typography that still felt oversized. Desktop catalog views should show more products per viewport and use a portrait card rhythm.

## Rules

- desktop supports up to 4 cards per row
- cards should be taller than wide
- product title uses compact `text-sm`
- price uses `text-lg`
- helper/metadata text uses 9–11 px scale
- cards use a single reusable component
- home and listing must not maintain independent card implementations
- images remain provider-driven via `StorefrontMediaDto`

## Implementation

Added reusable:

- `StorefrontProductCard`

Used by:

- `StorefrontHomePage`
- `StorefrontProductListingPage`

Grid behavior:

- mobile: 1 column
- small: 2 columns
- large: 3 columns
- extra large: 4 columns

The home featured section now exposes four provider-driven products so the 4-column desktop grid is visible.

## QA guardrails

Architecture tests require:

- both home and listing to use `StorefrontProductCard`
- both desktop grids to expose `xl:grid-cols-4`
- shared card minimum height to exceed its expected desktop width
- no `text-xl` or `text-2xl` inside the product card component

Browser QA verifies at 1365 px:

- four home cards share the same first-row top coordinate
- four listing cards share the same first-row top coordinate
- measured card height is greater than width
- no horizontal overflow
