# B7.5 · Storefront Visual Density Reset

## Baseline

- Repository: `LuisHdezE/WebBlueprint`
- Base: `main@2e7978443a2462f8f3ed8e9c0ed4acd20abbae4f`
- Branch: `feat/storefront-visual-density-reset`
- Trigger: visual review after B7 deployment

## Problem

The Storefront was functionally progressing but visually too oversized for a commercial catalog:

- page titles consumed excessive vertical space,
- hero blocks dominated the first viewport,
- cards used large radii/padding/min-heights,
- product content started too low,
- desktop density was closer to a presentation page than an ecommerce storefront.

The desired direction is closer to the compact commercial rhythm previously used on ZoFloridane: smaller type hierarchy, tighter chrome, faster access to categories/products and more useful information per viewport.

## Scope

This block is presentation-only.

Adjusted:

- Storefront shell/header/footer density
- `/store`
- `/store/products`
- product detail
- cart
- checkout
- customer sign-in/register

## Shared visual primitives

Added:

- `StorefrontPageIntro`
- `StorefrontSectionIntro`
- `storefrontSurfaceClass`

These centralize the compact Storefront heading/surface rhythm instead of solving every screen with independent one-off CSS.

## Density rules

Desktop Storefront pages now follow these constraints:

- main page headings target `text-3xl` to `text-4xl`, never `text-5xl`/`text-6xl`
- primary vertical page padding targets 20–24 px rather than 40–48 px
- standard surfaces use `rounded-2xl`, not 2rem mega-radius containers
- cards favor 12–16 px internal spacing
- product/media placeholders have reduced minimum height
- filters use a narrower sidebar
- summary panels use narrower sticky columns
- shell controls are shorter and use smaller labels
- content sections enter the viewport sooner

## Guardrails

Architecture tests reject reintroduction of:

- `text-5xl`
- `text-6xl`
- `rounded-[2rem]`
- `min-h-[28rem]`

inside Storefront presentation pages.

Browser QA additionally verifies on desktop:

- Storefront home H1 computed font size <= 40 px
- Storefront header remains <= 150 px tall
- categories begin before 700 px from viewport top
- listing H1 computed font size <= 40 px
- first product card begins before 620 px
- no horizontal overflow
