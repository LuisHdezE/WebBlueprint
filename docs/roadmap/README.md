# Roadmaps de WebBlueprint

## Roadmap vigente

La dirección actual del producto está gobernada por:

- `0003-composer-first-roadmap.md`

Después del cierre visual de G1, el producto entra en **G2 · Composer Foundation**. El catálogo maestro sigue mostrando todas las vistas disponibles, mientras que Composer pasa a gobernar identidad, plantilla, tema, selección, secuencia, preview y exportación mediante un único Blueprint Manifest.

Regla central:

> **Selección = Preview = Export.**

## Roadmaps históricos

- `0002-general-ui-template-roadmap.md`: rebaseline que fijó el catálogo UI general y el shell G1.
- `0001-initial-development-roadmap.md`: recorrido inicial U0–U2 y capacidades legacy.

Se conservan como evidencia del recorrido, pero no gobiernan el orden actual cuando entren en conflicto con `0003-composer-first-roadmap.md`.
